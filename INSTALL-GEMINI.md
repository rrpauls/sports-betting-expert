# Install as a Gemini Gem

1. Extract `sports-betting-expert-gemini-v1.0.0.zip`.
2. At `gemini.google.com`, open **Explore Gems** and choose **New Gem**.
3. Name it `Sports Betting Expert`.
4. Copy the complete contents of `gemini-gem-instructions.md` into **Instructions**.
5. Under **Knowledge**, upload every Markdown file from `gemini-knowledge/`.
6. Preview with: `Объясни, какие данные тебе нужны для проверки value в футбольном матче.`
7. Click **Save**. Preview alone does not save the Gem.
8. Start a new conversation inside the saved Gem and run the smoke prompts from `INSTALL.md`.

The Gem is not synchronized with GitHub. Replace its instructions and Knowledge files when installing a newer release. Do not share it publicly unless the included instructions and knowledge are suitable for public viewing.
